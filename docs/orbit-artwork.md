# Between Two Worlds

The hero artwork was created with the built-in image-generation tool for this portfolio. It is conceptual artwork, not a photograph or a claim of client work.

Project asset: `public/art/orbit-studio.webp` (1536 × 1024, 186,950 bytes).

Prompt used:

> Use case: stylized-concept. Asset type: original editorial artwork for Adief Al Syarif's technology and photography portfolio, landscape 1536x1024. Create a meticulously crafted Blender-style cinematic still life: a sculptural brushed titanium orbital gyroscope with three broad interlocking rings around one small warm luminous orange glass sphere, suspended above a dark rust sandstone surface. A single tiny moon far behind. Black-brown studio-space background, copper rim light from right, soft ivory key light, real machined-metal detail, elegant quiet science-fiction, sophisticated art direction. Composition: object centered slightly right, entire sculpture visible with generous margins, asymmetrical orbital rings at beautiful angles, soft contact shadow. Palette near-black, muted cream, burnt orange and silver. No text, no logo, no watermark, no interface. This is conceptual artwork, not a photograph of the user's work.

The separate procedural model `public/art/adief-orbital-sculpture.glb` contains three orbital rings and an amber core with four editable materials. It matches the web viewer's simplified geometry; it is not an exact reconstruction of the generated artwork. It was exported as glTF 2.0 binary with Three.js. Its binary header, declared length, four meshes, and four materials were checked. It can be imported into Blender using glTF import. Blender was not available in this session, so no native `.blend` or Blender render was produced or verified.

The Mars terrain image was already in this project and retains its NASA/JPL-Caltech/MSSS credit. No substitute photographs are attributed to Adief.
